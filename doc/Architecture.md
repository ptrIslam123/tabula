### **Основные компоненты**

```
┌─────────────────────────────────────────────────────────────┐

│                   (Web, Mobile App, API)                    │
└─────────────────────────┬───────────────────────────────────┘
                          │ HTTPS
┌─────────────────────────▼───────────────────────────────────┐
│                    ENTRY POINT (Nginx)                      │

                      |
```

## Компоненты с их ответственностью

### **1. Entry Point (Nginx)**
- **Что делает**: Принимает все запросы, решает, куда направить
- **Почему нужен**: FastAPI сам по себе медленный для статики, Nginx умеет быстро отдавать файлы и держать много соединений

### **2. Application Layer (FastAPI)**
- **Что делает**: Вся бизнес-логика — регистрация, создание заказа, поиск товаров
- **Ключевые сервисы**:
  - **Auth Service**: Вход, регистрация, проверка прав
  - **Product Service**: CRUD товаров, поиск, фильтрация, создание заказов, смена статусов
  - **Notification Service**: Уведомления (email/push)

### **3. База данных (PostgreSQL)**
- **Что хранит**: Все постоянные данные — пользователи, товары, заказы
- **Особенность**: Это «источник правды», всё остальное — лишь кэш
